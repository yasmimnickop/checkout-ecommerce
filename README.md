Como os códigos foram desenvolvidos
Para realizar o trabalho, utilizamos a linguagem de programação JavaScript, por meio do Visual Studio Code. Primeiro, organizamos
as operações que seriam desenvolvidas pelo grupo: multiplicação e subtração. Depois, criamos um código separado para cada
operação, utilizando funções para realizar os cálculos. Na multiplicação, o programa recebe dois valores e multiplica um pelo
outro. Já na subtração, recebe os valores e realiza a diminuição, incluindo o número 10,5 solicitado na atividade. Após escrever
os códigos, fizemos testes para verificar se os resultados estavam corretos e se tudo funcionava como esperado. Assim,
conseguimos compreender melhor como funciona a programação e como os códigos podem ser utilizados para resolver cálculos de
maneira automática.
